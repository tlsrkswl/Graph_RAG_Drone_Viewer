# Strict Community Hierarchy v3

Community KG now uses exact-level visibility.

- L0: only entities with an L0 membership
- L1: only entities with an L1 membership
- L2: only entities with an L2 membership
- L3: only entities with an L3 membership
- Nodes in the same active-level community use the same color.
- Child community colors remain related to their Level-0 root hue.
- Community backgrounds use clipped radial gradients.
- Community KG uses the existing community-aware fixed coordinates. Positions do not jump during zoom.
- Knowledge Graph mode is unchanged.
